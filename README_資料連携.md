# 資料の追加・表示

TODOの行、または直下にカーソルを置き、作業メニューから「資料を追加」を選びます。画像／PDFをファイル選択画面で選び、短い表示名を入力します。ファイルは作業ハブのimgへコピーされます。すでにimgの直下にあるファイルはコピーせず参照します。元のファイルや同名のファイルを上書きしません。

```markdown
- [ ] 曲の構成を考える
  メモ：
    展開を整理する
  資料: [画像: 構成図][img-1]
  資料: [PDF: ノート][img-2]

[img-1]: img/20261005_001.png
[img-2]: img/20261005_001.pdf
```

「資料を開く」は、カーソルのあるTODOに付いた資料をWindowsの既定アプリで表示します。複数ある場合は表示名を選びます。手書きの参照や `資料: [PDF: ノート](img/note.pdf)` も使えます。参照先はimg内の対応ファイルに限ります。ファイル名に空白がある場合は参照定義内で `%20` と記載します。

対応形式: PNG、JPG/JPEG、GIF、BMP、WebP、TIF/TIFF、PDF。OneNoteのPDF出力も同じ操作で追加できます。絵文字は使いません。

TODOの保存時には元の本文をバックアップします。未保存の編集も一緒に保存されます。資料のコピー後にTODO保存が失敗した場合、コピーは残し、その場所をエラーに表示します。

短い参照をMeryの本文でクリックして開く機能ではありません。「資料を開く」マクロを使用してください。Geminiの今日やるグループ分けはTASKS.md内の資料リンク行をタスクと一緒に移動します。Google同期やLOG移動時の資料参照追従は未対応です。

ファイル選択には作業ハブ直下のpick-asset.ps1（Windows PowerShell・Windows Forms）を使用します。
