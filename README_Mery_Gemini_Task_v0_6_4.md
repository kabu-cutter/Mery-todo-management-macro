# Mery Gemini Task Macro v0.6.4 addon

## 修正内容

`TASKS.md` で `今日やる` が2つになる問題への修正です。

原因は主に2種類あります。

1. `### 今日やる` などのサブ見出しが重複している
2. `## 2026-xx-xx (...) 今日の作業` という今日の日付ブロック自体が2つできている

v0.6.4では、同じ今日の日付ブロックを丸ごと1つに統合してから、`今日やる` / `次にやる` / `後で` / `置く` / `確認が必要` / `メモ` を整理します。

## 更新ファイル

- `Mery_TASKS今日分の重複項目を整理.js`
- `Mery_今日の開始テンプレートを挿入.js`
- `Mery_選択範囲を今日のTASKS欄へ追加.js`

## まず実行するもの

すでに `今日やる` が2つになっている場合は、まずこれを実行してください。

```text
TASKS.md 今日分の重複項目を整理
```

整理前にバックアップを作ります。

```text
C:\Projects\ai-work-hub\TASKS_backup_YYYYMMDD_HHMMSS.md
```

## どう直るか

整理前:

```md
## 2026-06-19 (金) 今日の作業

### 今日やる
- [ ] A

## 2026-06-19 (金) 今日の作業

### 今日やる
- [ ] B
- [ ] A
```

整理後:

```md
## 2026-06-19 (金) 今日の作業

### 今日やる
- [ ] A
- [ ] B

### 次にやる
- [ ]

### 後で
- [ ]

### 置く
- [ ]

### 確認が必要
- [ ]

### メモ
- [ ]
```

## 今日の開始テンプレートの変更

`今日の開始テンプレートを挿入` も変更しました。

今日分がすでにある場合は、もう1つ追加しません。  
既存の今日分へ移動して、メッセージを出します。

これで、開始テンプレートを押し直しても同じ日付ブロックが増えにくくなります。
