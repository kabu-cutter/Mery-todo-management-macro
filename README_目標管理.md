# 年・月・週の目標とTODO期限

`Mery_作業メニュー.js` の「年・月・週の目標と期限を管理」から利用します。既存の `TASKS.md` と `LOG.md` は変更せず、目標は作業ハブ直下の `GOALS.md` に分けて保存します。

`GOALS.md` は通常のMarkdownファイルとして直接編集できます。マクロは追加・期限設定を補助するもので、ウィザードを使わずに項目を書き換えたり、チェックを付けたりして構いません。

## 目標の作り方

「目標を順番に作成（複数可）」を使うと、質問に答えるだけで年→月→週→TODOの階層をまとめて追加できます。各段階で「同じ親の下にもう1件追加しますか？」と確認するので、年間目標・月目標・週目標・TODOを複数登録できます。期限日と時間帯は任意です。途中でキャンセルすると、今回入力した分は追加されません。

1. 「目標ファイルを開く / 作成」で `GOALS.md` を開きます。
2. 「年間目標を追加」で対象年と目標を入力します。
3. 年目標の行にカーソルを置いて「選択した目標の下に追加」を実行し、月目標を作ります。
4. 月目標の行から同じ操作で週目標を作ります。
5. 週目標の行から同じ操作で行動TODOを作ります。

階層は字下げで表します。同じ親の下に子目標を複数並べる場合は、同じ字下げにします。年→月は2字、月→週は4字、週→TODOは6字です。年目標・月目標・週目標・TODOのそれぞれに複数の子項目を追加できます。子目標の期間は入力時に変更できます。週は ISO 週（例: `2026-W41`）で、月曜始まりです。

## 期限と時刻

行動TODOの期限日は任意です。時刻はさらに任意で、日付だけなら時刻入力を空欄にします。

```markdown
- [ ] 書類を提出する <!-- mery-due:2026-10-08 -->
- [ ] 面談 @09:30-10:00 <!-- mery-due:2026-10-08 -->
```

期限マーカーは既存の Google Tasks 連携でも使われている形式です。`TASKS.md` と `LOG.md` の予定日は従来どおり日付見出しから判定するため、このマクロの期限設定対象から除外しています。

編集前に同じフォルダーへタイムスタンプ付きバックアップを作ります。未保存の文書は変更せず、先に保存を促します。Google や VueMinder への自動同期は行いません。カレンダーへの連携は、ローカル運用を確認してから別途追加します。
