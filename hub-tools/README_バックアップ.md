# 作業ハブのバックアップ

保存先は未設定です。毎日21:00の定期実行は、保存先を設定すると登録されます。現在はタスクを登録していません。

## 保存先を設定する

PowerShellで作業ハブに移動して実行してください。下の `E:` は実際の保存先ドライブに変更します。

```powershell
cd C:\Projects\ai-work-hub
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-backup.ps1 -Destination 'E:\ai-work-hub-backup'
```

設定のみ行って定期実行を登録しない場合は、末尾に `-NoSchedule` を付けます。
手動バックアップは次のコマンドです。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\backup.ps1
```

## 保存される内容

- TASKS.md、LOG.md、COMMAND.md、OUTBOX.md、既存のバックアップ.mdを含むすべての.md、notes、img、マクロ、Git履歴など、作業ハブ全体をコピーします。
- 普段は「最新」フォルダから探せます。次の保存が完了したとき、前回の「最新」を「履歴/YYYY-MM/日時」に移します。削除されたファイルも過去の履歴に残ります。
- 「バックアップ一覧.md」には、各回の保存先と追加・更新・削除されたファイル名を記録します。初回は全ファイルが追加として記録されます。
- 過去のバックアップを削除しません。空き容量が足りなくなった場合は失敗として記録します。
- 保存先の識別ファイルを確認します。未接続や別のUSBにドライブ文字が割り当てられた場合は保存を中止します。
- 途中で失敗したコピーは `.partial` のフォルダに残ります。完了したコピーには `backup-manifest.json`（ファイル一覧とSHA-256）が入ります。
- 実行ログと最新結果は作業ハブの `.backup` に保存します。この実行記録自体はコピーしません。
- シンボリックリンク／ジャンクション先はコピーしません。同期中（sync.lockが存在）は中止します。

## 動作条件

Windows PowerShell 5.1とrobocopyを使用します。21:00はPCのローカル時刻です。PCにログイン中かつ起動中で、保存先が接続されている必要があります。時刻を逃した場合は、タスクスケジューラの実行可能になった時点で開始する設定です。USBの接続だけでは再実行しないので、未接続による失敗後は手動実行するか翌日の実行を待ってください。

エディターで未保存の内容はバックアップされません。コピーはファイル単位なので、実行中に編集すると異なる時点のファイルが混在することがあります。復元は必要なファイルを「最新」または「履歴」からコピーします。作業ハブを上書きする前に現在の内容も保存してください。

## Meryから使う

作業メニューの「作業ハブのバックアップ…」から、今すぐ保存／最新／履歴／一覧／保存先の設定を選べます。メニューを増やしすぎないよう、バックアップ操作はこの一項目にまとめています。「一覧を開く」はエクスプローラーで一覧ファイルを選択します。Meryへドラッグして読めます。

スクリプトはディスクの初期化・フォーマット・パーティション変更を行いません。
