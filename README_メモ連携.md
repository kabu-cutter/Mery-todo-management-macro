# TODOのメモ

作業メニューの「このTODOにメモを作る」と「関連メモを開く」を使います。

## メモ欄のルール

```markdown
- [ ] メモセクションを追加する
  メモ：
    TODOとメモを連携させたい。
    後から本文を検索したい。
  関連メモ: [📄 メモ1][memo-1]

[memo-1]: notes/20261005_001.txt
```

メモ欄はTODOの直下に字下げして `メモ：` と記します。半角コロンの `メモ:` も認識します。本文はラベルより深く字下げします。手書きも可能です。次のTODO・見出し・字下げされていない本文に達したら、そのTODOの範囲は終わります。

作業メニューの「TASKS.mdのメモ欄のインデントを整える」は、本文の行をタスクから4字下げに揃えます。自動整形する場合は、[マクロ] → [カスタマイズ] のイベント設定で「ファイルを開いた時」に `Mery_TASKSメモ欄のインデントを整える.js` を割り当てます。作業ハブの `TASKS.md` 以外では何もせず、整形時はバックアップを作成します。関連メモ・資料の行は変更しません。

## このTODOにメモを作る

- TODOの行や直下のメモにカーソルを置き、本文を選択せずに実行すると「メモ欄（メモ：）を挿入・開く」「TXTメモを作りリンクを追加する」「メモ欄の本文をTXTにする」を選べます。
- メモ欄の挿入は `メモ：` と入力スペースを追加し、そこへカーソルを移します。既存の手書き欄があれば再利用します。
- メモ本文を選択して実行すると、選択内容をTXTへ写し、TODOの末尾に「関連メモ」のリンクを追加します。元の本文は残します。ラベルとリンクは選択に含めません。
- 「メモ欄の本文をTXTにする」は、そのTODOの `メモ：`／`メモ:` の下の本文全体を写します。選択は不要です。手書きの欄にも使え、空の本文では作成しません。元の本文と既存のTXTは残し、新しいTXTを作ります。
- 本文なしでTXTを作る場合は、タイトル・作成日時・元の文書を記したファイルを開きます。詳しい追記はTXT側へ書きます。
- TXTは `C:\Projects\ai-work-hub\notes` に保存します。ファイル名は `20261005_001.txt` のような日付と連番にし、TODO名はTXT内に保存します。既存ファイルを上書きしません。
- 関連メモは `[メモ1][memo-1]` のように短く表示します。保存先は文書末尾の `[memo-1]: notes/...` にまとめます。Meryの編集画面では、この短い表示をクリックして開くことはできません。「関連メモを開く」で開きます。別の文書へTODOをコピーするときは、参照定義も一緒にコピーしてください。
- 保存されたTXTに本文があれば、作成時にリンクの名前へ `📄` を表示します。管理用のタイトル・日時・元の文書だけで本文が空のTXTにはアイコンを付けません。「関連メモを開く」はTASKS.mdを変更しないため、TXTを手動編集した後のアイコン更新は行いません。
- 元の文書は先に保存しておきます。リンクやメモ欄を挿入する際は、未保存の編集も含めて文書を保存します。変更前の本文は `.memo_backup_日時_連番.md` に残します。

## 関連メモを開く

TODOまたはその直下にカーソルを置いて実行します。リンクが複数あれば選択メニューを表示します。TXTはMeryで開きます。この操作でTASKS.mdを保存しません。リンク切れのファイルを勝手に作り直しません。

以前の直接パス・ファイルURL・参照リンクも読み込めます。見出しが消えた参照リンクも、開くために一時的に解釈します。開く操作ではTASKS.mdやTXTを書き換えず、リンクの選択メニューにも長いパスを表示しません。

長いURLの表示より短い表記を優先します。短い表記のクリックで開く操作は、別の表示UIや専用プラグインを使う場合の今後の課題です。

TXTメモはMeryの標準ファイルオープンで別タブに開きます。縦書き表示が必要な場合は、Meryの［表示］メニューから切り替えてください。本文の保存形式は通常のUTF-8テキストです。

## 現在の範囲と次の課題

- 今回の更新版のランダマイズは、メモ欄の空行も含めてタスクと一緒に移動します。
- メモ本文・TXTはGoogleには送信しません。Geminiの今日やるグループ分けではTASKS.md内のタスク直下にあるメモ欄・リンク行を一緒に移動します。Google同期やLOGへの移動時の追従は今後の対応です。TXT自体は独立して保存されます。
- 選択は通常のテキスト選択のみ。複数選択・矩形選択は対象外です。
- 本文検索とタグ分類は今後追加します。

## 作業メニューの整理案

今回はメモの2項目を隣接配置します。大きな再編は後で、実際の使用頻度を見て決めます。

候補は「TODO操作」「メモ」「Gemini整理」「同期・保守」のサブメニュー化。よく使う操作は先頭に残し、メモ欄の挿入とTXT作成は「このTODOにメモを作る」の中で選択します。必要なら「最近使った操作」を先頭に出す方式も検討します。

Meryの選択範囲APIは [公式マクロリファレンス](https://www.haijin-boys.com/wiki/マクロリファレンス:3:Selection_オブジェクト) に基づきます。実際のMery上での手動確認は必要です。
